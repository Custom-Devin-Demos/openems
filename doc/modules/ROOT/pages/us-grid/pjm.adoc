PJM Interconnection is the regional transmission organization (RTO) for 13 US states and the District of Columbia. PJM publishes market results via https://dataminer2.pjm.com[Data Miner 2]. The bundle `io.openems.edge.timeofusetariff.pjm` retrieves **day-ahead hourly locational marginal prices** (`da_hrl_lmps`) for a configurable pricing node (pnode) or zone and provides them as `TimeOfUseTariff`.

Compared to xref:us-grid/comed.adoc[ComEd Hourly Pricing], the PJM feed

* covers the whole PJM footprint (any pnode/zone, e.g. `COMED`, `PECO`, `BGE`, `DOM`, ...),
* is already denominated in `$/MWh`,
* requires a (free) Data Miner 2 API subscription key.

=== Configuration

[cols="2,1,1,4", options="header"]
|===
|Property |Type |Default |Description

|`id` |String |`timeOfUseTariff0` |Component-ID
|`alias` |String | |Human-readable name shown in the UI
|`enabled` |boolean |`true` |
|`apiKey` |String | |Data Miner 2 subscription key, sent as HTTP header `Ocp-Apim-Subscription-Key`. Register at https://apiportal.pjm.com/[apiportal.pjm.com] to obtain one.
|`pnodeId` |long |`33092371` |Pricing node ID. The default is the COMED zone.
|`zone` |String |`COMED` |Zone name (informational; used for logging and the debug log)
|`pollingIntervalMinutes` |int |`60` |How often the API is queried. Day-ahead results are published once per day (around 13:30 ET), so hourly polling is sufficient.
|`ancillaryCostsPerMwh` |double |`0` |Constant surcharge (in `Currency/MWh`) added to every price
|`httpTimeoutSeconds` |int |`15` |HTTP connect/read timeout
|`maxRetries` |int |`3` |Retries per polling cycle before `CONSECUTIVE_FAILURES` is incremented
|===

=== Data source

Request (simplified):

[source]
----
GET https://api.pjm.com/api/v1/da_hrl_lmps
    ?rowCount=50000&startRow=1
    &datetime_beginning_ept=<today 00:00> to <tomorrow 23:59>
    &pnode_id=33092371
Ocp-Apim-Subscription-Key: <apiKey>
----

Fields used from the response: `datetime_beginning_utc` (preferred over `datetime_beginning_ept`, which is in `America/New_York` local time and ambiguous during the DST fall-back hour), `pnode_id` and `total_lmp_da` (`$/MWh`).

Hourly LMPs are expanded into four identical 15-minute values as required by `TimeOfUsePrices`. No unit conversion is necessary (`$/MWh` = `Currency/MWh` with `Currency = USD`).

=== Channels

[cols="2,1,4", options="header"]
|===
|Channel |Type |Description

|`HttpStatusCode` |INTEGER |HTTP status of the last request (`200` on success, `401`/`403` on an invalid API key)
|`LastSuccessfulUpdate` |LONG |Epoch seconds of the last successful price update
|`ConsecutiveFailures` |INTEGER |Number of polling cycles that failed in a row
|`PnodeId` |LONG |The configured pnode ID
|===

== Finding a pnode ID

Data Miner 2 provides the `pnode` feed (`https://api.pjm.com/api/v1/pnode`) listing all pricing nodes with `pnode_id`, `pnode_name`, `zone` and `voltage_level`. Utility zones (e.g. `COMED`, `PECO`) are the usual choice for residential and small commercial customers; large customers with nodal pricing use their specific bus pnode.
